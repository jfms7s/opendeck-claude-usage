Budget

Optional. With a budget, This month shows a bar and turns Watch / Risk / Critical as spend crosses the marks below. Leave blank for none.

Short press (key or dial) cycles Today (UTC) → 7 days → This month. Hold to refresh.

Admin key

Shows billed spend for your whole Claude Console organization, from the Usage & Cost Admin API. It needs an Admin key (sk-ant-admin01-…): regular API keys can't read usage, and individual accounts can't create Admin keys.

Put the key on one line in ~/.config/opendeck-claude-usage/admin-key, then run chmod 600 ~/.config/opendeck-claude-usage/admin-key. The key never passes through OpenDeck or this page.

Numbers lag about 5 minutes, and "today" is a UTC day. The key shows NO KEY, KEY PERMS or NOT ADMIN when something's wrong.
